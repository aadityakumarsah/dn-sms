# DN-SMS Setup & Deployment Guide

## 🚀 Getting Started

### Prerequisites
- Bun 1.0+ installed
- PostgreSQL 12+ running
- Python 3.11+ (for FastAPI backend)
- Node.js 18+ (optional)

### Project Components

| Component | Tech | Directory | Port |
|-----------|------|-----------|------|
| **SMS API** (primary) | Bun + Prisma | `server/` | 4000 |
| **Auth API** (user/role management) | FastAPI + SQLAlchemy | `app/` | 8000 |
| **Frontend** | React 19 + Tailwind | `client/` | 3000 |
| **Reverse Proxy** | NGINX | `nginx/` | 443 |

---

## 1. SMS API — Bun/Prisma Backend

### Setup

```bash
# Install dependencies
cd server
bun install

# Environment
cp server/.env.example server/.env
```

Edit `server/.env`:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/dn_sms"
DIRECT_URL="postgresql://user:password@localhost:5432/dn_sms"
JWT_SECRET="your-secret-key-minimum-32-characters-long-please"
PORT=4000
FRONTEND_URL="http://localhost:3000"
NODE_ENV="development"
SUPER_ADMIN_EMAIL=admin@school.com
SUPER_ADMIN_NAME="DN-SMS Super Admin"
SUPER_ADMIN_PASSWORD=your-super-admin-password
CLOUDNARY_NAME=your-cloudinary-cloud-name
CLOUDNARY_API_KEY=your-cloudinary-api-key
CLOUDNARY_API_SECRET=your-cloudinary-api-secret
```

### Database

```bash
# Create migrations
bun prisma migrate dev --name init

# Seed database
bun prisma db seed
```

### Start

```bash
bun run dev
# → http://localhost:4000
```

## 2. Auth API — FastAPI Backend

### Setup

```bash
# Python virtual environment (recommended)
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Environment
cp .env.example .env
```

The root `.env` is auto-generated with a secure `SECRET_KEY`. Verify it contains:

```env
SECRET_KEY=<auto-generated-64-char-key>
DATABASE_URL=postgresql+asyncpg://sms_user:sms_password@localhost:5432/sms_db
REDIS_URL=redis://:redis_password@localhost:6379/0
```

### Database

```bash
# Run Alembic migrations
alembic upgrade head

# Seed roles and super admin
python scripts/seed.py
```

Seeded credentials: **admin** / **Admin@123**

### Start

```bash
uvicorn app.main:app --reload --port 8000
# → http://localhost:8000/docs (Swagger UI)
```

## 4. Docker Compose (Full Stack)

Run all services together:

```bash
# From project root
docker compose up -d
```

This starts:
- **PostgreSQL** (port 5432) — primary DB
- **Redis** (port 6379) — caching/rate limiting
- **FastAPI app** (port 8000)
- **NGINX** (ports 80/443) — reverse proxy

Then apply migrations and seed:

```bash
docker compose run --rm alembic upgrade head
docker compose run --rm app python scripts/seed.py
```

## 5. NGINX Reverse Proxy (Production)

The `nginx/nginx.conf` handles:
- SSL/TLS termination on port 443
- Proxying `/api/` to the FastAPI backend
- Serving static files from `/uploads/`
- Rate limiting (100 req/s, burst 200)
- Security headers (HSTS, X-Frame-Options, etc.)

For local development without SSL:
```nginx
# Comment out the HTTPS server block
# and uncomment or use the HTTP block on port 80
```

### SSL Certificates

```bash
# Place certificates
mkdir -p ssl
# Copy your certs:
cp /path/to/fullchain.pem ssl/cert.pem
cp /path/to/privkey.pem ssl/key.pem

# Or use Let's Encrypt
certbot certonly --standalone -d api.yourdomain.com
cp /etc/letsencrypt/live/api.yourdomain.com/fullchain.pem ssl/cert.pem
cp /etc/letsencrypt/live/api.yourdomain.com/privkey.pem ssl/key.pem
```

## 🧪 Testing

### Test the Bun/Prisma API (SMS Backend)

```bash

  -H "Content-Type: application/json" \
  -d '{"email": "admin@dn-sms.local", "password": "your_password"}'

  -H "Content-Type: application/json" \
  -d '{"email": "...", "password": "...", "schoolSlug": "test-school"}'
```

```bash

curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
```

## 📦 Production Deployment

Choose either **Docker Compose** (recommended) or **Manual** setup.

### Option A: Docker Compose (Recommended)

```bash
# 1. Clone and configure
git clone https://github.com/aadityakumarsah/dn-sms.git /opt/dn-sms
cd /opt/dn-sms
cp .env.example .env
# Edit .env — set SECRET_KEY, DB passwords

# 2. SSL certificates
mkdir -p ssl
cp /etc/letsencrypt/live/api.yourdomain.com/fullchain.pem ssl/cert.pem
cp /etc/letsencrypt/live/api.yourdomain.com/privkey.pem ssl/key.pem

# 3. Launch all services
docker compose up -d

# 4. Run migrations & seed
docker compose run --rm alembic upgrade head
docker compose run --rm app python scripts/seed.py
```

### Option B: Manual Setup

**Bun/Prisma backend:**
```bash
cd server
export DATABASE_URL="postgresql://prod_user:prod_pass@prod_host:5432/dn_sms_prod"
export JWT_SECRET="generate-a-long-random-string"
export PORT=4000
export FRONTEND_URL="https://app.yourdomain.com"
export NODE_ENV="production"
export CLOUDNARY_NAME=...
export CLOUDNARY_API_KEY=...
export CLOUDNARY_API_SECRET=...

bun prisma migrate deploy
NODE_ENV=production bun src/index.ts
```

**FastAPI backend:**
```bash
cd /opt/dn-sms
source .venv/bin/activate
export SECRET_KEY="long-random-string-32-chars-min"
export DATABASE_URL="postgresql+asyncpg://user:pass@host:5432/sms_db"

alembic upgrade head
python scripts/seed.py
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

**Frontend:**
```bash
cd client
bun run build
# Output in client/dist/ — serve via NGINX or deploy to Vercel
```

### NGINX Configuration (Production)

The repo includes a production NGINX config at `nginx/nginx.conf`:

```nginx
# SSL termination, reverse proxy, rate limiting, static files
# Configured for:
#   - HTTPS on port 443
#   - Proxies /api/ to FastAPI backend (upstream fastapi_backend)
#   - Serves /uploads/ static files
#   - 100 req/s rate limiting

# For the Bun API, add another upstream:
upstream bun_backend {
    server localhost:4000;
}

location /api/auth/ {
    proxy_pass http://bun_backend;
    # ... proxy headers
}
```

### SSL/HTTPS

```bash
certbot --nginx -d api.yourdomain.com
```

## 🔍 Troubleshooting

### Bun Server: "Cannot find module 'auth.handlers.ts'"
```bash
cd server && bun install
# Ensure imports use .ts extension
```

### FastAPI: "SECRET_KEY field required"
```bash
# Root .env is missing. Create it:
cp .env.example .env
# Or set env variable:
export SECRET_KEY="your-32-char-min-secret-key"
```

### FastAPI: "ModuleNotFoundError: No module named 'app'"
```bash
# Run from project root directory
cd /path/to/dn-sms
# Or set PYTHONPATH:
export PYTHONPATH="${PYTHONPATH}:/path/to/dn-sms"
```

### FastAPI: "password cannot be longer than 72 bytes"
```bash
# bcrypt version incompatibility. Install compatible version:
pip install bcrypt==4.1.3
```

### FastAPI: "relation 'roles' does not exist"
```bash
# Migrations not applied. Run:
alembic upgrade head
```

### Database: "DATABASE_URL not set"
```bash
# Check .env file exists
cat .env | grep DATABASE_URL
# Or set manually
export DATABASE_URL="postgresql://..."
```

### Auth: "JWT token is invalid"
```bash
# Verify SECRET_KEY / JWT_SECRET in .env
# Token was created with same secret
# Check token hasn't expired
# Bun and FastAPI use SEPARATE JWT secrets — tokens are not interchangeable
```

### School: "School not found"
```bash
# Verify school slug is correct
bun prisma studio
# Check School table for actual slug
```

### CORS: "CORS errors in browser"
```env
# Bun server/.env
FRONTEND_URL="http://localhost:3000"
# FastAPI .env
CORS_ORIGINS=["http://localhost:3000"]
```
